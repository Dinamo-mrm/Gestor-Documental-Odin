## TRA-02 — Criterios de aceptación prioritarios

### Login
1. Usuario activo con contraseña válida puede autenticarse.
2. Usuario inactivo o rol inactivo es rechazado.
3. Login exitoso registra `LOGIN` en `log_accesos` y crea sesión `ACTIVA`.
4. Login fallido registra `LOGIN_FALLIDO` sin almacenar contraseña.
5. Logout cierra la sesión y registra `LOGOUT`.

### Radicación
1. Se genera número E/S consecutivo anual.
2. El número es único.
3. Se almacenan metadatos obligatorios y anexos/documentos asociados.
4. Se genera comprobante PDF con QR.
5. Las operaciones relevantes quedan trazadas en historial/auditoría.

### Dashboard
1. KPI se consulta desde datos persistidos.
2. Vencidos y próximos a vencer usan la fecha de vencimiento persistida.
3. Las notificaciones mostradas pertenecen al usuario autenticado.

### RBAC
1. Los permisos provienen de `rol_permisos`.
2. Endpoints administrativos requieren permisos específicos.
3. Un usuario no puede consultar/marcar como leída la notificación de otro usuario.
4. Las pruebas finales deben ejecutarse con usuarios de cada rol y registrar resultado.
